# 👤 User Service Example

This is a minimal **Spring Boot microservice** that demonstrates how to integrate the 
[common-security-lib](https://github.com/Hunuru9/common-security-lib) 
to role-based authorization using **Keycloak** and **JWT tokens**.

---

## 🔐 Features

- ✅ Secures all endpoints using the shared `common-security-lib`.
- 🔒 Authorizes access based on user roles defined in the token.
- 🧪 Contains example endpoints to demonstrate security behavior.
